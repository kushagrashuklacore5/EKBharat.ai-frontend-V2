# Labeling tools (Phase 3)

Planned:
- `record_tool/` — a web page that records mock-exam sessions (video + browser events +
  timestamps) with a scripted "scenario" mode that cues actors what to do and when, so
  segments come pre-labelled.
- `label_config.xml` — Label Studio config for temporal segment labels and bounding-box
  labels for the custom objects.

Built in Phase 3, after Phase 2 (full per-frame feature set + calibration + baseline risk).
